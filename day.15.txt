Queries and Sub Queries

What is Sub Query?
it is a query inside another query.
it is written inside parenthesis() and its result is used by the outer query.
it is aslo called as inner query,nested query,inner query

Purpose of Subquery
to break down complex problems into smaller queries.
to use the result of one query as input to another.
to avoid multiple steps(write in a single query instead of temp tables).

general syntax:
select column_list from table
where colun OPERATOR(select column from table where condition);

types of subqueries
1.single row-subquery
single row-subquery returns extactly one row and one column. they use comparision operators like =,<,>=,>,<=,!=
characteristics:
returns only one value
can use single-value comparsion operator
if subquery returns no rows or multiple rows it causes an error

syntax:
select column
from table
where column operator(select column from table where condition);

2.multi-row subquery
(a)multi row subquery IN
A multi row subquery returns more than one row. the IN operator is used to when you want to caompare a value with multiple values returns by the subquery.

characteristics:
returns multiple rows.
use the IN operator.
checks whether a value exists in the list returned by thee subquery.
equivalent to multiple OR condition
most commly used for matching values.

syntax:
select column from a table
where column IN(select column from table where condition);

(b)multi row subquery (ANY/SOME)
it returns multiple rows .when using ANY or  SOME .the condition is true if it matches at least one value returns by the subquery

characteristics:
returns multiple values.
ANY and SOME are interchangble.
condition is true if any of the values satisfy the condition.
often used with IN,>ANY,<ANY,>=ANY....etc

syntax:
slect column from table
where column OPERATOR any/some (select column from table where conditions);

(c)multi row subquey ALL
The ALL Operator means the condition must be true for all values returned by the subquery.

characteristics
conditions must be true for all values in the subquery result.
often used with >ALL,<ALL,>=ALL,<=ALL
>ALL means greater than the maxmimum value
<ALL means less than minimum value.

syntax:
select column from table
where column operator all(select column from table where condition);


3.nested subquery
nested subquery are subqueries within subqueries.they can be multiple levels deep and are executed from innermost to the outermost.

characteristics
multiple levels of nesting.
inner queries execute first.
can combine different types of subqueries
useful for complex conditions

syntax:
select column-list from table
  where column=(select column from table where column=(select column from table where condition));

4.corelated subquery
corelated subquery are subquery that reference column from outer query.
unlike regular subquery that execute once.corelated subqueries execute once per each row processed by the outer query

characteristics
refernce column from outer query
executes multiple times(once per outer row).
cannot be execute independetly.
often used with Exists/NOT EXISTS.
generally slower than non-corelated subquery.

syntax:
select column from table1 outer_alias
 where condition(select column from table2 inner_alias
                        where inner alies.column-outer_alias.column);

5.exist/not exist subquery
exist is used to test weather a subquery returns any rows. it returns TRUE if the subquery returns at least at one row .FALSE otherwise.
NOT EXISTS return TRUE if the subquery retunrs no rows.

characteristics
returns TRUE/FALSE(boolean results)
more efficient that IN For lager datasets.
often used with corelated subquery.
stops execution as soon as first match is found.
select clauses in EXISTS doesn't matter(often use SELECT 1).

SYNTAX:
SELECT COLUMN FROM TABLE1
where exists(select 1 from table2 where condition);

syntax:
select column form table1
where NOT EXISTS(select 1 fro table2 where condition);
