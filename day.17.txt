Transaction
Transaction-the process of combining all related operations into a single unit and executing then according to the rule "either all opeartion should succeed or more 
should succeed" is called transaction management.

A transaction is considerd a single unit of work amd follows the principle"either all or none:;
Example:Funds Transfer
consider a money transfer process b/w two accounts:
Debit amount from the sender's account
Credit amount into the reciver's account
both operations should be excuted as a single successfuly, but crediting
the receivers account fails, it may lead to data inconsistency problems.

There are two types of transactions:
1.Local transaction
2.Global transaction

1.Local transaction:
In Local transactions all operations of a transaction are executed on the same database.
example:
funds transfer from one account to another account where both accounts belong to the same bank.

2.Global transaction
In Global transaction all operations of a transaction are executed on the different database.
example:
funds transfer from one account to another account where both accounts belong to the different bank.

ACID Properties:
Atomicity: all or nothing.
Consistency: the database remain in a valid state.
Isolation: transactions do not interface with each other.
Durability: committed changes are permanent.

TCL:Transaction Control Language
1.commit
commit is used to permantely save all changes made during the current transaction into the database.
once committed
changes become permanent
other users can see the changes.
you cannot undo the changes using rollback
2.rollback
it is usde to undo all changes made the current transaction before a commit.
if something goes wrong.roll back restore the database to its previous state.
3.save point

Introduction to Stored Procedures
A stored procedure is a named,precompiled collection of one or more sql statements that is stored inside the database and can be executed called whenever requried.
instead of sending long block of sql from an application every time,the application simply calls the procedure by name.

use of stored procedures:
1.performance
2.reusability
3.security
4.reduced network traffic
5.maintainability
6.consistency

advantages
faster execution after completion.
reduced duplicate sql.
supports transaction,loops,conditions,varibles...etc
easy maintainence.

Disadvantages:
1.Debugging can be difficult
2.Vendor specific syntax
3.Complex procedures may become hard to maintain

Syntax:
DELIMITER //
CREATE PROCEDURE procedure_name()
BEGIN
 --- sql statements
END //
DELIMITER

IN parameter
--> An IN parameter is used to pass a value into a stored procedure 
--> The procedure can use the value, but changes made to the parameter inside the procedure are not returned to the caller

Syntax:
CREATE PROCEDURE procedure_name(IN parameter_name datatype)
BEGIN
    sql statements
END;
DELIMITER;
